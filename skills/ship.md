# Ship

Turn an idea into a concrete, shippable plan.

## Process

1. Restate the goal in one sentence.
2. List the smallest set of changes that achieve it.
3. Identify what can be deferred.
4. Propose a PR structure (files, commits, tests).
5. Call out risks and how to verify.

## Output

```markdown
## Goal
...

## Changes
- [ ] ...

## Verification
...

## Out of scope
...
```

Prefer shipping a small, correct thing over a big, speculative one.
