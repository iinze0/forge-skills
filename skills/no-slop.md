# No Slop

Remove generic AI writing and code patterns.

## Rules

1. Prefer concrete, specific language over vague adjectives.
2. Avoid phrases like "robust", "seamless", "elevate", "leverage", "cutting-edge", "delve".
3. In code: prefer clear names, early returns, and explicit error handling over clever abstractions.
4. In UI copy: write like a human who knows the product.
5. After generating, do a pass and replace any remaining slop.

## Red flags to fix

- Overly formal tone
- Unnecessary complexity
- Generic comments
- "In this tutorial we will..." style

Make it sound like a competent engineer wrote it, not a language model.
